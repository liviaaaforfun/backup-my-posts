把網站放上網路

網站就是「① 網站（可以用於上傳公開）」這個資料夾，不需要伺服器，也不用寫程式。下面提供兩種常見的做法，選一種就好；方案與費用以各平台的規定為準。

兩者都是第三方服務，方案、限制與費用以各平台公告為準；這裡只整理寫教學當下的規格，順序依字母排列。點選卡片會切換到該平台的步驟。

  1. 註冊並登入 Cloudflare到 dash.cloudflare.com 註冊帳號，可以直接用 Google 帳號登入。
  2. 打開 Workers & Pages左邊選單「組建」（Build）底下，點「運算」（Compute）展開，再點「Workers & Pages」。
  3. 建立應用程式按右上角的 建立應用程式 Create application。在「建立新項目」（Make something new）清單中，選最下面的「Upload your static files」。
  4. 選擇資料夾出現「上傳和部署」（Upload and deploy）頁面。點虛線框裡的 資料夾 folder，選擇解壓縮後的「① 網站（可以用於上傳公開）」後上傳。也可以直接把資料夾拖進虛線框。
  5. 取名稱檔案清單下方的「Worker 名稱」（Worker name）會先填好一個隨機名稱，可以改成好記的英文小寫，例如 my-backup。右邊顯示「可用」（Available）就代表名稱沒被用過，網址會是 my-backup.你的帳號名.workers.dev。
  6. 部署按右下角的 部署 Deploy。這時每個檔案旁會開始轉圈圈（正在上傳），檔案大約 150 MB 時要等 1 分鐘左右，請不要關掉頁面。
  7. 完成上傳完會自動跳到這個網站的頁面。上方的 ….workers.dev 連結就是網址，也可以按右上角的 造訪 Visit 打開。
限制：免費方案一個網站最多 20,000 個檔案，每個檔案最大 25 MB。超過 25 MB 的影片，工具會先留在「② 存檔」、不放進網站，所以不會卡住；還是想放的話，看下方「想放超過 25 MB 的影片？」。
之後要更新網站？
  1. 用工具產生新的 zip 並解壓縮。
  2. 到「運算」（Compute）→「Workers & Pages」，在清單點你的網站名稱。
  3. 按右上角的 新部署 New deployment，進到「上傳靜態檔案以更新 Worker」（Upload static files to update your Worker）。
  4. 點 資料夾 folder 選擇新的「①」資料夾，再按右下角的 部署 Deploy。網址不會變。
想用自己買的網址？

在網站頁面上方切到「網域」（Domains）分頁，按 ＋ 新增網域 Add Domain。網址需要先加入同一個 Cloudflare 帳號。

想刪除網頁？

刪除只會讓網站從網路上消失。你電腦裡的 post-backup.zip 和資料夾都不受影響，之後想重新上線，再上傳一次就好。

  1. 到「運算」（Compute）→「Workers & Pages」，在清單點你的網站名稱。
  2. 上方切到「設定」（Settings）分頁，捲到最下面的「危險區域」（Danger zone）。
  3. 在「刪除 Worker」（Delete Worker）那一列，按 🗑 刪除 Delete。
  4. 跳出的視窗會請你輸入網站名稱確認，輸入後再按 刪除 Delete，網址就會立刻失效。

搜尋引擎可能還會暫時留著舊的搜尋結果，通常幾天到幾週內會自己消失。

  1. 建立儲存庫登入 github.com，按右上角的 ＋ ▾ → 選「New repository」。「Repository name」填英文名稱，例如 my-backup；「Choose visibility」維持「Public」（免費方案的網站需要公開）。其他不用改，按右下角的 Create repository。
  2. 上傳第一批檔案建好後的頁面上，點「Quick setup」那一區的 uploading an existing file。打開「①」資料夾，把 index.html、data.js 和 assets 資料夾一起拖進「Drag files here to add them to your repository」框，等檔案清單出現，按下方的 Commit changes。
  3. 上傳 media 資料夾回到儲存庫首頁，按 Add file ▾ → 選「Upload files」，把 media 資料夾整個拖進去，再按 Commit changes。（一次最多只能上傳 100 個檔案，所以要分兩批。）
  4. 開啟網站上方切到「Settings」分頁，左邊選單點「Pages」。在「Build and deployment」：「Source」維持「Deploy from a branch」；「Branch」把 None ▾ 改選「main」，旁邊維持「/ (root)」，按 Save。
  5. 完成等一分鐘左右重新整理同一頁，上方會出現「Your site is live at https://你的帳號.github.io/my-backup/」，按 Visit site 就能打開。

之後要更新網站？

只有新增貼文，沒有隱藏任何東西

一樣用 Add file ▾ →「Upload files」，照上面的兩批方式把新的「①」資料夾內容拖進去，按 Commit changes。同名檔案會直接覆蓋，網址不會變。

有隱藏貼文，或拿掉了圖片

GitHub 上傳只會新增或覆蓋檔案，不會刪掉舊檔案，隱藏貼文的圖片會繼續留在網路上；就算刪掉資料夾，GitHub 的歷史紀錄裡還是看得到。建議這樣做：

  1. 照下方「想刪除網頁？」的「整個刪掉」，把儲存庫刪除。
  2. 用同一個名字重新建立儲存庫，照上面的步驟重新上傳並開啟網站。網址不會變。
想用自己買的網址？

在「Settings」→「Pages」的「Custom domain」欄位填入網址，按旁邊的 Save。

想刪除網頁？

刪除只會讓網站從網路上消失。你電腦裡的 post-backup.zip 和資料夾都不受影響，之後想重新上線，再上傳一次就好。

  • 只想先下線、保留檔案：「Settings」→「Pages」，把「Branch」從「main」改成「None」，按 Save。（同一頁的「Unpublish site」在你下次上傳檔案後會自動重新上線，所以建議用改成 None 的方式。）
  • 整個刪掉：「Settings」頁捲到最下面的「Danger Zone」，按 Delete this repository。跳出的視窗依序按 I want to delete this repository → I have read and understand these effects，輸入畫面上提示的「帳號/儲存庫名稱」，再按 Delete this repository。如果跳出「Confirm access」，照畫面驗證身分（例如收驗證信）後就會完成刪除。

想放超過 25 MB 的影片？

Cloudflare 和 GitHub 都不收超過 25 MB 的單一檔案，所以工具預設不放進網站。想放的話有兩種做法，都在工具的「整理貼文」裡操作（上方篩選選「超過 25 MB 的影片」就能一次找出來）：

做法一：換成壓縮後的影片

  1. 先把影片壓縮到 25 MB 以下。Mac 可以用內建的 QuickTime Player：打開影片 → 上方選單「檔案」→「輸出為」→「720p⋯」，存成新檔案。還是太大的話改選「480p⋯」。
  2. 回到工具，在那支影片下方按「換成壓縮後的影片」，選剛剛存好的檔案。
  3. 重新按「產生網站」。原本的大檔案仍會留在「② 存檔」，不會遺失。

做法二：自己上傳到影音平台，再放連結

  1. 工具不會幫你上傳影片，這一步要自己做：先把影片上傳到你自己的 YouTube 等影音平台帳號（可以設成只有拿到連結的人才看得到），再複製那支影片的網址。
  2. 回到工具，在那支影片下方按「改放影片連結」，貼上剛剛複製的網址。
  3. 重新按「產生網站」。網站上那支影片的位置會變成「▶ 觀看影片」的連結。
公開之前想一下
  • 網站上線後，知道網址的人都看得到，也可能被搜尋引擎找到。
  • 不想公開的貼文，回工具按「隱藏」再重新產生；隱藏的貼文和它的圖片都不會出現在「①」裡。
  • 只想自己留存的話，不用上傳也可以：直接打開「①」裡的 index.html 就能瀏覽。
