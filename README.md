# 貼文備份網站產生器

<sub>適用 Threads 匯出檔</sub>

把從 Meta「匯出你的資訊」下載的貼文資料（JSON 格式 zip），整理成一個可以瀏覽、搜尋的備份網站。

帳號被盜、被停用或誤刪的時候，你的貼文、圖片和串文都還留在自己手上。

## 特色

- **資料不會上傳**：所有處理都在你自己的瀏覽器裡完成，這個工具沒有伺服器，也不會把檔案送到任何地方。
- **可以整理**：產生網站前，可以加標籤、隱藏貼文、設定防雷，也能挑選網站外觀。
- **可以接續更新**：之後重新匯出時，把上次產生的網站和新的匯出檔一起拖進來，就能合併成新版。
- **公開與否自己決定**：產生的網站可以只留在電腦裡看，也可以照工具內的「上線教學」放到 Cloudflare 或 GitHub Pages。預設會加上「不讓搜尋引擎收錄」的設定。

## 使用方式

1. 打開工具網頁：`https://<帳號>.github.io/<儲存庫名稱>/`（或下載這個儲存庫，直接用瀏覽器打開 `index.html`）。
2. 照頁面上的第 1 步，從 Meta 匯出資料（格式選 JSON）。
3. 把下載好的 zip 拖進頁面，整理完按「產生網站」，會下載 `post-backup.zip`。
4. 解壓縮後打開裡面的 `index.html` 就能瀏覽。想公開的話，再看工具內的上線教學。

### 瀏覽器需求

需要比較新的瀏覽器：Chrome / Edge 103 以上、Safari 16.4 以上、Firefox 113 以上。

### 已知限制

- 產生的網站整包需小於 4 GB，檔案數需少於約 65,000 個。資料量很大時，也可能因為瀏覽器記憶體不足而失敗。
- 超過 25 MB 的影片不會放進網站，因為常見的免費托管平台有單檔大小限制。可以改放壓縮過的版本或外部連結，工具內有說明。
- Meta 如果更改匯出檔的格式，工具可能需要跟著調整。

## 聲明

這是基於 Meta 服務提供的匯出功能而製作的工具，與 Meta、Threads、Instagram 沒有任何關聯，也不代表平台立場。
要不要公開、使用哪個平台以及相關費用，由使用者自主決定。請只備份你自己的帳號資料，並留意貼文中其他人的內容與隱私。

## 開發

純靜態網頁，沒有建置步驟和外部相依套件。

- `index.html` / `app.js` / `app.css`：工具本體
- `lib/zip.js`：讀寫 zip（讀取使用瀏覽器內建的 `DecompressionStream`）
- `lib/importer.js`：解析匯出檔、接續上次的備份
- `template/`：產生出來的網站（index.html / site.css / site.js）
- 修改 `template/` 之後，執行 `python3 build_templates.py` 更新 `lib/templates.js`。這樣用 `file://` 直接打開也能運作。
